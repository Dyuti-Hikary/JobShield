# JobShield Express.js Backend

This is the actual JobShield REST API built with Express.js and running on Node.js.

Install:

```bash
npm install
```

Run:

```bash
npm start
```

Server:

```text
http://localhost:5000
```

Test:

```text
http://localhost:5000/api/health
```

The server includes API examples for all ten functional requirements.
